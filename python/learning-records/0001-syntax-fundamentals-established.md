## What was learned

- Python uses indentation (not braces) to delimit code blocks
- Variables need no type declaration (dynamic typing)
- Functions declared with `def`, no return type
- `for x in collection:` iterates values directly (not indices)
- f-strings for string interpolation: `f"{name} is {age}"`
- Naming convention is `snake_case` (PEP 8)
- Run scripts with `python3 file.py`, interactive with `python3` (REPL)

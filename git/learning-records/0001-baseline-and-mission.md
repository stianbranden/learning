# Baseline established: fluent in add/commit/push, no mental model

User self-reports `add` / `commit` / `push` / `pull` as habitual, branches as shaky, and no understanding of what happens underneath. Works in a mix of CLI and VS Code's Source Control panel. Mission is dual — solo work safety (never lose code, undo anything) and team collaboration (branch, PR, conflicts without fear).

**Implications:** Do not spend lessons on basic command syntax — the gap is the model, not the vocabulary. Teach the commit graph and the three trees first, since both halves of the mission (recovery and collaboration) are downstream of them. Every lesson should name the VS Code GUI equivalent alongside the CLI command.

**Status:** active. Awaiting evidence on Lesson 01 (three trees) before treating that model as established.

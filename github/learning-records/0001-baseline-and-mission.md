# Baseline and mission

**2026-08-07 — Course started.** Driver: broad platform tour, no single task forcing it (see [[../MISSION.md]]). Prerequisite git skills already established end-to-end in `../git/` (solo safety + PR/remote workflow both retention-verified, see `../git/learning-records/0003-mission-covered-end-to-end.md`) — this course does not re-teach git, only GitHub-the-platform on top of it.

**Starting level:** light exposure — opened issues/PRs before, seen Actions run, no fluency on what's possible across Issues, Actions, Projects, Pages, security tab.

**Sequence chosen:** natural order — Issues/PRs first (closest to known git flow), then Actions, Projects, Pages, security. Real repo (`stianbranden/learning`, has a GitHub remote) is the practice ground, not a throwaway sandbox.

**Lesson 01 delivered:** Issues — anatomy (title/body/labels/assignee/milestone), and the closing-keyword trick (`Fixes #N` in a commit or PR auto-closes on merge). Not yet retention-tested. Win is unlocked, not verified: create a real issue on the repo and close it via a real commit.
